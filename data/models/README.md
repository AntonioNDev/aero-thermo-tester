# data/models

Put `.stl` / `.obj` mesh files here for non-primitive objects (a plane, a
human figure, etc.). Free sources: NASA 3D Resources, Sketchfab (check each
model's license before using it in a public repo), Thingiverse.

Not needed until Phase 1's mesh-import step — start with procedurally
generated primitives (box, sphere, cone) first so you can validate the
physics before geometry complexity enters the picture.
